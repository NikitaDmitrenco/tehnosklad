## Policy (from feedback — must appear in report)

Для сценариев, затронутых **known bugs**, Playwright должен:

1. Assert **INTENDED** behavior (ADMIN_GUIDE / code intent), **не** фактический баг.
2. Оборачивать assertion в `test.fail()` + комментарий `// known bug BUG-0X: <one line>`.
3. Suite остаётся green; тест сам «падает» (помечает fail) когда баг исправлен.
4. В report Locator / Expected column: «intended …; currently buggy → mark test.fail()».
